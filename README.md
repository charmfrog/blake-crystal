# Blake Crystal Dock (v1.0)

> **"The Purest is the Strongest"**  
> 가장 순수한 것이 가장 강하다 · Zero-Build Single-File Modular Platform

An **ultra-lightweight (~28KB), zero-dependency modular web workstation** powered 100% natively by modern browser standards. 

No bundlers, no build steps, no external frameworks. Just pure web architecture orchestrating independent single-file micro apps through sandboxed slots and memory-speed message buses.

---

### ✨ Core Philosophy & Highlights

- **Zero-Build, Zero-Dependency**: Runs instantly out of the box with zero `npm install` or configuration. Open the HTML file, and you are ready.
- **Pure Native Isolation**: Utilizes modern `<iframe sandbox>` security to ensure that micro modules operate completely independently without cross-contaminating memory or code.
- **Ultra-Fast Memory Bus**: Communicates seamlessly across isolated slots via standard `window.postMessage` at native memory speeds (0.001s).
- **Universal Minimal Protocol (`BLAKE_MICRO_APP_v1`)**: Connects any tool using a lean 3-key packet structure: `{ protocol, action, payload }`.
- **True Software Sovereignty**: Immune to platform lock-in, vendor policies, or server shutdowns. Built to work offline forever.

---

### 📦 Quick Start

1. Download or clone `blake_dock.html`.
2. Double-click to launch in any modern browser (Chrome, Safari, Edge, Firefox).
3. Drag & drop compatible single-file micro apps into **DOCK SLOT #1** and **DOCK SLOT #2** to instantly compose your tailored creative workspace.
